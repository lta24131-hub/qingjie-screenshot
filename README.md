# Luma

原名“轻截”。名称和图标已更新；为兼容旧版，程序文件 `QingJie.exe`、数据目录及已有登录启动项保持原路径，现有贴图、历史、快捷键和启动偏好不迁移、不丢失。桌面入口改为 **Luma**。

轻量 Windows 截图、标注、屏幕贴图和截图翻译工具。独立 C# / WPF 实现，不捆绑 Electron 或浏览器内核。默认英文优先，英文附带约 4 MB 本地模型，中文使用 Windows OCR。其他语言按需安装，不随基础包捆绑。运行文件约 11 MB（不含附加语言包、备份和贴图）。不是 Snipaste 或微信的官方产品。

## 使用

### 换电脑使用

1. 在仓库的 **Releases** 页面下载 `Luma-Windows-x64.zip`。不要下载 Code → Download ZIP（那是源码）。
2. 完整解压到一个固定文件夹，双击 `QingJie.exe` 即可免安装使用。不要只复制 EXE，`x64`、`tessdata` 和旁边的 DLL 都需要保留。
3. 可选：在解压文件夹运行 `powershell -NoProfile -File .\install.ps1`，安装到当前用户目录并创建桌面、登录启动快捷方式。若系统策略不允许运行脚本，直接使用第 2 步的免安装方式，不需要修改安全策略。
4. 支持 Windows 10/11 **x64**、.NET Framework 4.8；不适用于 macOS。中文 OCR 需要 Windows 中文文字识别组件。截图和贴图可以离线使用；中英翻译可另装离线包，其他语言使用在线翻译。

### 按需安装其他语言

托盘右键 → **设置 → 识别语言**。默认“英文优先”，不加载任何附加语言。可选择日文、韩文、俄文、法语、德语、西班牙语、葡萄牙语、意大利语、阿拉伯语、泰语、越南语，点击“下载并启用”；大小约 0.5–3.7 MB，界面显示各包大小。最多启用一种附加语言，已安装但未启用的模型不加载。用完可切回英文优先，无需重启；在已经打开且有识别结果的窗口中，请重新打开图片或重新截图。

语言包保存在 `%LOCALAPPDATA%\QingJie\languages`，可在设置中卸载，贴图不会删除。这些是文字识别包，不是翻译模型；安装后本机识别可以离线，非中英翻译仍需在线服务。语言包使用固定版本的官方 GitHub 下载源，流式下载并校验 SHA-256；不要求代理，但国内网络可能不稳定。下载失败不改当前设置，也可选择“导入语言包”，导入同一版本的 `.traineddata` 文件。版本固定为 `tesseract-ocr/tessdata_fast` 的 `87416418657359cb625c412a48b6e1d6d41c29bd`，文件名和校验值见 `src/OcrLanguagePacks.cs`。

### 可选中英离线包

设置 → **离线中英包**，提供下载、取消、检查更新、更新、卸载。默认不下载，不随基础 ZIP 捆绑。双向模型及运行组件下载约 **181 MiB**，安装后约 **285 MiB**；请预留至少 800 MiB 用于临时解压和安全更新。下载遵循现有系统网络配置，上游 python.org、PyPI、argos-net.com 和 GitHub 更新源不保证在所有国内网络可达。

安装后，在“翻译服务”选择 **离线翻译 · 中文 ↔ 英文** 并应用。输入翻译、截图原位翻译、所选文字翻译统一使用所选服务。离线模式绝不自动改用联网翻译；缺少模型、其他语言、损坏或超时均明确报错并保留原图 / 原文。仅支持中文和英文，小模型对专业词、长句和指令句可能误译或漏译，重要内容请人工复核。

离线组件保存在 `%LOCALAPPDATA%\QingJie\offline-translation`，无需系统 Python、显卡或管理员权限。模型仅在任务期间由短期 CPU 进程加载，完成 / 取消 / 超时后退出；不常驻内存。文字走匿名管道，不进入参数、临时文件或网络。图片各区域独立批量翻译，序号由程序维护，不依赖模型复述编号；中英识别仍走已有 OCR。

检查更新只在点击时连接本仓库 `main/offline/catalog.json`。清单包含兼容版本、下载大小、HTTPS 来源及 SHA-256；没有自动检查或后台下载。候选包在独立目录校验、解压并做中英双向自检后才原子切换；失败或取消保留旧包，成功后回收旧版本。卸载仅删除离线组件，不删除贴图、历史、偏好或 OCR 语言包，也不会自动启用在线服务。更新源不可达时如实提示失败，不冒充“已是最新”。

### 贴图保存和迁移

在文件资源管理器地址栏输入 `%LOCALAPPDATA%\QingJie\pins` 即可找到贴图数据。它在用户目录中，与软件安装文件分开，不会上传 GitHub。

迁移时先退出两台电脑上的Luma，将旧电脑的整个 `pins` 文件夹复制到新电脑的同一位置，再打开软件。原图、译图、显示位置、旋转翻转和收起状态都会迁移；不要只复制 PNG。若目标电脑已有贴图，请先备份整个目标文件夹，避免覆盖自己的记录。

### 快捷操作

- **输入翻译 Ctrl+Alt+T**：打开独立的小窗口，输入或手动粘贴中文，点“翻译”或按 Ctrl+Enter，默认译成英文，再点“复制译文”。也可从托盘右键或主窗口进入；快捷键冲突时保留菜单入口。支持切换译成中文。输入时不自动发送、不会读取剪贴板或自动代发消息，不保存输入历史，不加载 OCR。最多 5000 字，修改输入、切换语言或关闭窗口会取消旧请求，防止旧译文覆盖新内容。
- **截图目标语言**：截图和文字浏览窗口的翻译按钮旁可选择“译成中文 / 译成英文”。截图默认中文，与输入翻译窗口独立；改变目标会清除旧译图并恢复原图，再点击翻译生成新译图。整图和所选文字使用当前窗口的同一目标语言。
- **设置**：从主窗口“设置”按钮或托盘右键菜单进入。可随时开关“开机自动启动”，并查看、打开贴图保存文件夹。免安装运行时也可启用自启动，请不要再移动程序文件夹。
- **自定义快捷键**：设置 → 快捷键，点击按键并输入新组合，保存后立即生效。支持 F1–F24 或 Ctrl / Alt 组合；冲突或保存失败保留原按键。恢复默认后需点保存。下文 F1、F3、Ctrl+Alt+T 均为默认值。
- **极简输入浮窗**：圆角、系统毛玻璃半透明背景，文字和按钮保持清晰；系统不支持或高对比度模式回退浅色背景。无大标题栏，拖动顶部空白移动；译文区域和“复制”仅在有结果时出现，长文可滚动，Esc 或右上角 × 关闭。不会开机常驻此窗口，不截取桌面做模糊，不引入额外界面库。

- **F1**：截图，手动框选后显示简洁横向工具栏。
- **截图翻译（文/A 图标）**：译文直接显示在当前截图选框内，保留选框和工具栏，不新建贴图、不跳到屏幕左上角。可继续标注、复制、保存；再次点击切回原图。只有点击“贴到屏幕”才生成贴图。改变选区会取消旧请求并清除旧译图；失败时保留原图。
- **文字选择（方框 T 图标）**：打开图片浏览窗口，左侧大图、右侧列出全部识别文字。右侧可按住左键连续拖选、反向拖选或跨行选中，出现“复制 / 翻译所选”。只有选中的内容被翻译；其余全文一直保留。也可在原图上的文字间拖选，与右侧选区联动。
- 图片浏览窗口的顶部工具栏支持贴图、缩放、适应窗口、1:1、复制图片、整图翻译、收起/展开文字侧栏和保存图片。整图翻译在左侧原位显示，重复点击切换原图；右侧选词翻译结果只在需要时展开，不替换全文。
- 矩形、椭圆默认为空心。标注时滚轮改变线宽，鼠标显示相应大小圆圈；圆圈和粗细提示不会保存进截图。
- 支持箭头、画笔、文字、马赛克、撤销/重做、保存 PNG、复制、贴到屏幕。
- **F3**：优先找回最近收起的贴图；没有待找回贴图时粘贴剪贴板图片。托盘菜单另有“粘贴剪贴板图片”，可跳过找回。
- 贴图可拖动；滚轮缩放，Ctrl+滚轮调透明度。鼠标移入显示复制、保存、×。× 或聚焦贴图后按 Esc 只收起，不永久删除，可用 F3 找回。
- 贴图周围有轻柔阴影，鼠标移入时边缘显示淡绿色微光；装饰不计入图片尺寸，不进入复制或保存的图片。
- 贴图工具栏使用 26 DIP 小按钮，悬浮在图片上方外侧，屏幕边缘空间不足时自动调整位置。移入图片时出现，移到工具栏时保持显示，离开后收起。
- 工具栏“旋转 / 翻转”菜单支持顺时针/逆时针 90°、水平翻转、垂直翻转和恢复原始方向。采用无插值像素变换，不反复压缩原图；复制和保存使用当前方向，重启和 F3 找回保留旋转/翻转状态。
- 桌面、托盘和窗口使用统一的 Luma 单色双光束图标，透明底、无底板和外框；16–256 像素多尺寸由 `assets/BuildIcon.cs` 生成，不需要图像运行库。
- 一次 Esc 取消整个截图，包括所有显示器的遮罩和正在编辑的文字；Enter 复制；Ctrl+S 保存；Ctrl+Z/Y 撤销/重做。

## 保存与重启恢复

贴图原图、译图、位置、大小、透明度以及是否收起，保存在本机 `%LOCALAPPDATA%\QingJie\pins`。

退出程序或重新登录后恢复仍在屏幕上的贴图，收起的贴图不会自动弹出，仍可用 F3 找回。清单采用原子替换和备份；清单损坏时保留原 PNG 的恢复入口。已完成的翻译图片离线恢复，不会在恢复时自动重新上传文字。当前不自动清理历史贴图，贴图越多占用空间越大。

安装脚本首次安装默认创建当前用户的开机登录快捷方式，参数为 `--background`；后续升级保留启动项是否存在的选择。不需要管理员权限。推荐在Luma的“设置”中关闭。关闭后需要手动启动Luma才会恢复贴图。如果曾在 Windows 任务管理器中禁用该启动项，还需在任务管理器中恢复启用。

## 隐私和翻译服务

截图、文字识别、保存、贴图在本机完成。设置 → 翻译服务可选择腾讯（默认）、Google、离线中英。只有显式点击翻译才处理文字；在线模式将相应文字通过 HTTPS 发给所选服务，不上传图片；离线模式不发送文字到网络。不自动切换服务。敏感文字应选择离线模式。贴图不会上传到 GitHub。

腾讯使用 `transmart.qq.com` 网页翻译接口，直连、不使用代理。Google 使用 `translate.googleapis.com` 公共网页接口，遵循系统已有代理；需要网络可访问 Google，应用不提供代理也不更改代理。均不要求密钥，但不是带可用性保证的正式付费 API，可能限流、拒绝或变更。Google 解析与错误路径已测试，当前网络曾拒绝请求，不能保证可用。网络失败不会删除原图。复杂背景上的文字替换不是图像修复；使用文字区域附近底色覆盖，原图始终单独保留。

腾讯请求直接连接，Google 和语言包下载遵循系统已有的网络设置，不修改代理配置。官方 GitHub 源在某些网络下可能无法访问，此时可使用已校验的本地语言包导入。

## 体积与内存

- 基础运行文件逻辑大小约 11 MB，ZIP 约 5 MB；英文 OCR 模型和引擎完整保留，没有降低截图分辨率。附加语言包只在用户选择后下载。
- 安装脚本对运行文件启用 Windows NTFS 无损压缩；实际占用随文件系统而变，不支持压缩的文件系统仍可正常运行。资源管理器的“大小”与“占用空间”不同，贴图和版本备份另计。
- 升级只备份发生变化的运行文件，不再重复备份相同 OCR 模型与 DLL。旧备份不会由安装脚本自动删除。
- OCR 在同一 EXE 的短期后台子进程中运行，通过仅限当前用户的本机命名管道传输无损像素和文字，不保存临时截图、不发送到网络。完成、取消或超时后退出，释放 OCR 引擎；英文和所选附加模型依次加载释放，同时只执行一个 OCR，避免多开叠加峰值。
- 最多并行两路在线翻译；离线推理串行执行。翻译文字缓存最多 64 条、字符内容约 128 KiB（对象开销另计），5 分钟失效，按服务、目标语言及离线包版本隔离；OCR 只缓存最近一张的小型文字和坐标结果（最多 500 个词、16000 字符），2 分钟失效。缓存不保留截图像素、不写磁盘、不设常驻清理定时器；到期后下次访问清理，退出后全部释放。
- 预处理改用单通道灰度缓冲，保留原有放大倍率、反色及灰度值。测试覆盖逐像素一致性、透明/深色背景、中英文混排、文字位置、取消、队列以及联网翻译。
- 使用 `staging\QingJie.MemoryProbe.exe` 可复测固定合成样本。测试数据不代表所有截图；图片尺寸、贴图数量和系统组件会影响实际内存。

## 系统要求与构建

Windows 10/11 x64，.NET Framework 4.8，以及 Windows 中文或英文 OCR 语言组件。系统组件本身不计入本应用文件大小；截图和贴图存储另计。

```powershell
.\build.ps1 -Test -OutputDirectory staging
```

首次构建先执行 `setup-ocr.ps1` 下载并校验固定版本的本地英文识别组件。要执行完整测试，请先运行 `setup-ocr.ps1 -IncludeLanguageTests` 下载测试用附加模型。测试模型只复制到 `test-languages`，不进入安装包。编译器和 WinRT 元数据使用 Windows 自带路径，不需要 Node、Electron 或 .NET SDK。测试使用生成的示例文本图片。设置 `QINGJIE_LIVE_TEST=1` 可额外测试腾讯直连和语言包下载，只发送固定示例文字。组件授权见 THIRD-PARTY-NOTICES.md。

`QingJie.Tests.exe --offline-live` 下载并验证双向离线翻译，使用构建目录下独立的 `offline-live-test`，不操作实际用户离线包。更新清单只发布经过此测试的兼容组件；增加 Revision 后才视为更新，Schema 改变需同时更新主程序。`offline/worker.py` 与清单嵌入 EXE，基础软件不含 Python 或翻译模型。维护者研究脚本 `offline/setup-test.ps1` 仅写 `vendor/offline-research`。

```powershell
# 请先从托盘退出Luma，再运行安装；运行中时脚本拒绝覆盖，不会强制退出。
.\install.ps1
```

安装 EXE、配置、本地英文 OCR 依赖及说明，不安装测试文件，不卸载 Snipaste/eSearch。默认创建桌面“Luma”，首次安装创建登录启动快捷方式，升级保留启动项选择，安装后不自行启动。使用 `-NoStartup` 可跳过创建登录启动项。升级不删除旧版语言模型或备份。

截图文字按区域编号一起翻译，校验对应关系后才覆盖；接口若改变编号则保留原图。在相机、云台、立柱等设备上下文中，用少量术语规则纠正“弃牌/平衡环/身体”等错义。机器翻译仍可能出现措辞不准确，不能保证所有专业词语的翻译质量。

## 当前边界

默认英文优先，保留系统中文识别；其他语言需要在设置中安装并启用。浅色小字使用局部阈值补充识别，多语言段落按语言分组翻译后回填原位置。附加语言已通过基础合成样例测试，但小字、艺术字体、竖排和复杂混排仍可能出错；机器翻译也可能误译专业词语。

仍是早期版本，不能声称已完全复刻 Snipaste。暂不支持跨显示器连续框选、滚动长截图、贴图分组或原软件布局自动迁移。一次可在任一显示器框选；不同 DPI 的多屏环境仍需进一步实机验证。全局快捷键与其他软件冲突时可在设置中更换，不修改系统安全设置。

源码上传应使用此目录的 allowlist `.gitignore`，不要上传 dist/staging、系统贴图目录或旧软件备份。
